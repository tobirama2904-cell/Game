### ЭТАП 1 — Технический каркас (Неделя 1–2)
**Цель:** проект открывается в Godot 4, есть папки, базовые сцены, игрок, камера, ввод, сохранения (чекпоинты), меню, тестовый уровень. **Без геймплея — только каркас.**  
**Milestone:** `F5` запускает пустую сцену с игроком, который может ходить, прыгать, камера не ломается.  
**Definition of Done:**  
- [ ] Godot 4.2/4.3 установлен и работает в sandbox / на целевом железе  
- [ ] `project.godot` создан, нет ошибок при загрузке  
- [ ] `scenes/player.tscn` + `scripts/PlayerController.gd` — движение + камера  
- [ ] `scenes/glade.tscn` — визуальная сцена (блоки, свет)  
- [ ] `scenes/ui.tscn` — минимальный UI (здоровье / выносливость)  
- [ ] `scenes/main.tscn` — менеджер игры  
- [ ] `InputMap` настроен (WASD, jump, interact, pause)  
- [ ] Нет ошибок в консоли (`Output` чистый)  
- [ ] Ручной тест пройден: игрок не проваливается в пол, камера не вращается хаотично

**Риски:** отсутствие Godot в sandbox требует установки (см. `research.md`). **Если устанавливить нельзя — используем текстовый редактор + `godot --headless --script` для проверки синтаксиса.**

### ЭТАП 2 — Вертикальный срез 10–15 минут (Неделя 3–4)
**Цель:** одна зона Лабиринта, одна механика сдвига, один тип врага, один сюжетный момент, один катсценный фрагмент. **Стабильные 60 FPS на малофоне (poco f4) — цель, но проверяем отсутствие падений.**  
**Milestone:** игрок может пройти срез от начала до конца без блокеров, без падений, без ошибек в консоли.  
**Definition of Done:**  
- [ ] Сцена `glade.tscn` — вход, диалог с Чаком (линейный или с 1–2 выбором)  
- [ ] Сцена `maze_zone_01.tscn` — вход в Лабиринт, блоки для головоломки (3 блока, толкание)  
- [ ] Механика сдвига — секция сдвигается (через `AnimationPlayer` или `Tween`), игрок может пройти или умереть  
- [ ] AI Гривера — патруль, преследование, атака, смерть или уклонение  
- [ ] Катсцена — вступление (`cutscene_01.tscn`) + финал (`cutscene_03.tscn`)  
- [ ] Сюжетный момент — Томас находит подсказку, возвращается в Глэйд  
- [ ] Ручной чеклист пройден (см. `technical-design.md` раздел 8)  
- [ ] Время прохождения 10–15 минут (проверено 3 раза)  
- [ ] PDF или текстовый отчёт теста (что сделано, что не сделано, какие ошибки)

**Что входит в срез (не больше, не меньше):**  
- Глэйд (1 сцена) + Лабиринт (1 зона) + 1 Гривер + 1 головоломка + 3 катсцены (вступление, сдвиг, финал) + линейный диалог + базовый UI.  
- **Не входит:** другие зоны, другие враги, полная система диалогов с ветвлениями, полный звуковой дизайн, полноценная музыка, сохранение прогресса.

---

### ЭТАП 3 — Полировка среза (Неделя 5)
**Цель:** game feel, звук, UI, обучение, баланс, оптимизация, тесты. **Не добавляем новых механик.**  
**Milestone:** срез ощущается как «игра», не как прототип.  
**Definition of Done:**  
- [ ] Управление отзывчивое (без задержек, камера не ломается)  
- [ ] Физика стабильна (нет туннелирования, нет «залипания» в стенах)  
- [ ] AI не застревает (тест 5 повторений в изоляции)  
- [ ] Звук — минимальный, но есть (шаги, дыхание, тревога, событие сдвига)  
- [ ] UI — понятен (выносливость отображается, подсказки не перекрывают)  
- [ ] Обучение — первые 2 минуты объясняют правила (через Чака или текст)  
- [ ] Оптимизация — `Occlusion Culling` включён, `LOD` для моделей (если есть), `MultiMeshInstance3D` для блоков  
- [ ] Тесты ручные пройдены, отчет сохранён в `docs/test-report.md`

**Резервы:** если не влезает в неделю — вырезаем звук (оставляем только события) или сокращаем катсцены до 2 вместо 3.

---

### ЭТАП 4 — Расширение (Только после приёмки среза — неделя 6+)
**Цель:** больше локаций, врагов, механик, сюжета. **Не начинаем до тех пор, пока Этап 3 не принят.**  
**Milestone:** полный вертикальный срез принят, план расширения согласован.  
**Definition of Done:**  
- [ ] Приёмка среза (пользователь или тестировщик подтверждает прохождение)  
- [ ] Документ `docs/expansion-plan.md` — что добавляем (другие зоны, другие враги, более сложные головоломки, диалоги с выбором)  
- [ ] Архитектура не ломается (новые сцены используют существующие префабы)  
- [ ] Коммиты по задачам (`git commit -m "feat: add zone 02"`) — не одно крупное изменение

## 4. Блокирующие вопросы (без ответов — нельзя двигаться)

**Эти вопросы заданы в других документах; повторяем здесь как чеклист:**

1. **Версия Godot:** 4.2 LTS или 4.3? (Влияет на API, Jolt-совместимость, SDFGI.)  
2. **Установка в sandbox:** как получить Godot 4 (скачать релиз, apt, snap)? Нужна ли помощь для установки?  
3. **Зона среза:** первая секция Лабиринта (у входа в Глейд) или глубокий Лабиринт (сложнее визуально)?  
4. **Катсцены в срезе:** только вступление или также финал с возвращением?  
5. **Геймпад / только клавиатура?**  
6. **Сохранение:** чекпоинты или полноценное сохранение?  
7. **Язык текстов:** только русский или р/у?  
8. **Озвучка:** текст + синтез или только текст для среза?  
9. **Катсцена: сколько минут (30 сек или 2 мин)?**  
10. **Нужна ли Тереза в срезе или только намёк?**

> **Следующий минимальный шаг после согласования:** ответить на вопросы 1–5 (критичные для кода) и начать установку Godot + создание `player.tscn`.
