## 1. Godot 4.x — что это и какие версии актуальны

- **Godot 4.2 LTS** (стабильная, широко используется) и **4.3** (более свежий, улучшенный Forward+, SDFGI, новый Editor).  
- **Forward+** — основной рендерер для 3D. Поддерживает MSAA, SSR, SDFGI (Screen Space Directional Occlusion + Global Illumination), volumetric fog.  
- **Mobile / Vulkan:** Godot 4 использует Vulkan 1.2/1.3. На слабых GPU требует оптимизации (LOD + occlusion culling).  
- **Физика:** встроенный Godot Physics (Bullet-based) допустим для прототипа, но для «стабильных коллизий на скорости» рекомендуется **Jolt Physics** (плагин `godot-jolt`, доступен в Godot Asset Library и GitHub).  
- **Навигация:** `NavigationAgent3D` + `NavigationPolygon/NavigationMap` — стандарт для AI-перемещения в 3D.  
- **Анимация:** `AnimationPlayer`, `AnimationTree`, `Skeleton3D`, `AnimationMixer` — всё в коробке. Для катсцен — таймлайн на `AnimationPlayer` + `Camera3D`.  
- **Звук:** `AudioServer`, `AudioBusLayout`, `AudioStreamPlayer3D` — гибкая миксация, эквалайзеры, реверберация через шейдеры или сторонние плагины (если нужно).

## 2. Доступные инструменты и плагины (реально проверяемые)

| Инструмент / Плагин | Доступность в Godot 4 | Примечание |
|---|---|---|
| Jolt Physics (`godot-jolt`) | Да, GitHub / Asset Library | Рекомендуется для CharacterBody3D + RigidBody3D на скорости. Необходим для стабильного паркура. |
| Godot Asset Library (GAL) | Да, через Editor | Бесплатные 3D-модели, текстуры, звуки (CC0 / MIT). **Не копируем чужие IP-модели** (см. правила). |
| Godot Shader Textures / Procedural | Да, нативно | Noise, gradient, voronoi для стен лабиринта, без внешних файлов. |
| AI-генерация изображений (`generate_image`) | Доступна в этом окружении | Для ключевых артов (текстуры камня, фан-арт, UI). Есть ограничения по стилю. |
| `image_search` | Доступна | Для референсов, не для прямого использования в игре (авторские права). |
| Godot 4 Documentation | `docs.godotengine.org`, офлайн в редакторе | Проверяем перед написанием любого скрипта. |

## 3. Ограничения и риски (не предположения, а факты среды)

- **Без Godot Editor в этом sandbox:** до установки бинарника я могу писать `.gd` и `.tscn` в текстовом виде, но не могу визуально проверить сцены, не могу запустить проект из редактора, не могу проверить материалы в 3D-вьюпорте.  
- **CPU / GPU:** среда — виртуальный контейнер. Рендеринг в реальном времени будет медленным; целевой критерий — «стабильные 60 FPS на poco f4» — это цель, но в sandbox я могу проверить только отсутствие падающих FPS (нет блокеров, нет бесконечных циклов). **Полная оптимизация — на этапе 3 с реальным железом заказчика.**  
- **IP / Легальность:** это fan remake «Бегущий в лабиринте» (The Maze Runner / James Dashner). Не коммерческий проект. Нельзя использовать модели/текстуры из официальной игры или из реальных фильмов. **Имена персонажей и локаций из оригинала — разрешены как reference (номинативное использование в fan-фанфик/ремейке).** Ассеты — только сгенерированные или CC0/MIT.  
- **Звуки:** нет доступа к профессиональной звукозаписи. Для среза используются генерация / свободные библиотеки или синтезированные 2D-звуки через Godot (шум, синтезеры). **Полноценный звуковой дизайн — TODO после приёмки среза.**  
- **Сетка / LOD:** Godot 4 поддерживает LOD через `LODInstance3D` или через компонент `MeshInstance3D` + `LOD` в материале / сцене. Для лабиринта (много повторяющихся блоков) — лучше использовать `MeshInstance3D` + `GridMap` или `MultiMeshInstance3D`, но для среза достаточно повторяющихся сцен с `StaticBody3D` и `OccluderInstance3D`.
