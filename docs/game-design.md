# ЭТАП 0 — ГЕЙМДИЗАЙН (Game Design)

**Автор:** гейм-дизайнер / продюсер  
**Дата:** 2026-11-02  
**Статус:** черновик  
**Основа:** вселенная «Бегущий в лабиринте» (The Maze Runner, James Dashner; фильм 2014).  
**Примечание:** не оригинальная история — это fan remake с вертикальным срезом, повторяющим ключевые моменты первого акта (прибытие Томаса, знакомство с Глейдом, первый тест на сдвиг, столкновение с Гривером, побег/прорыв).

---

## 1. Жанр и тон

- **Жанр:** экшен-приключение с элементами выживания, паркура, стелса и простых головоломок.  
- **Тон:** тревожный, клаустрофобный, с резкими сменами на катастрофу и надежду. Никакого юмора — это не «лёгкий» labirin.  
- **Целевая аудитория:** фанаты оригинала + игроки, ищущие атмосферный 3D-экшен с исследованием.  

---

## 2. Core Loop (основной цикл)

```
Исследовать зону Лабиринта
   ↓
Решить пространственную задачу (блоки-пазл, сдвиг, высота)
   ↓
Избегать / противостоять Гриверу (стелс или бой/уклон)
   ↓
Найти ресурс/подсказку (карта, ключ, код, фрагмент памяти)
   ↓
Вернуться в Глэйд (безопасная зона) → взаимодействие с NPC
   ↓
Продвинуть сюжет (диалог, катсцена) → Открыть следующую секцию Лабиринта
```

**Для вертикального среза (10–15 мин):** цикл ограничен одной большой зоной (вход в Лабиринт + первая секция сдвига) и одним триггером сюжета (Чак просит Томаса помочь, происходит первый сдвиг, Томас видит Гривера, возвращается в Глэйд с подсказкой).

---

## 3. Механики (что реально работает в Godot 4 с Jolt + Navigation)

| Механика | Реализация в Godot 4 | Детали для среза |
|---|---|---|
| **Бег / Паркур (run / parkour)** | `CharacterBody3D`, `Velocity`, `move_and_slide()`, `InputAction` | Бег по стенам (только короткие участки, без бесконечного скалолазания — иначе физика ломается), прыжки с удержанием, подкат (roll) через `AnimationPlayer` + изменение коллайдера. |
| **Выносливость (stamina)** | `Float` переменная в скрипте игрока, UI `ProgressBar` | Бег и паркур тратят выносливость. При нуле — замедление, невозможен спринт. Восстановление только в покое или в Глэйде. **Важно:** это не RPG-бар, это «выживательный» элемент — игрок должен планировать маршрут. |
| **Страх / Адреналин (fear / adrenaline)** | Состояние в скрипте + постобработка (`CanvasModulate` или шейдер) | Когда Гривер видит игрока или игрок в темноте — экран слегка искажается, звук приглушается. Не RPG-стат, а визуально-звуковой эффект. |
| **Сдвигающиеся секции Лабиринта (The Changing)** | `GridMap` или `StaticBody3D` с анимацией позиции + `Tween` | Секция (квадрат 4×4 блоков) сдвигается по таймеру или триггеру. Игрок может быть зажат — смерть или урон. Для среза: одна секция сдвигается по таймеру (30 сек), давая игроку время пройти. |
| **Ближний бой / Уклонение** | `AnimationPlayer` для ударов + `Area3D` для зоны поражения | У игрока нет оружия в начале (это важно для сюжета). Бой — только уклонение, подкат, бросок предмета (камень). **Для среза:** один предмет (камень) — одно использование или ограниченный запас. |
| **Скрытность (stealth)** | `NavigationAgent3D` для врага + `RayCast3D` для зрения + `OccluderInstance3D` | Гривер видит игрока в радиусе ~10 м и под углом ~60°. Если игрок в тени или за стеной — не видит. Гривер издаёт звуки — игрок может слышать и прятаться. |
| **Простые головоломки** | `StaticBody3D` с триггером + `AnimationPlayer` | Пример: три каменных блока, которые нужно толкнуть в правильный порядок, чтобы открыть проход. Без сложного UI — только физика + визуальный фидбек. |

## 4. Управление (клавиатура + геймпад)

- **WASD / Левый стик:** движение.  
- **Shift:** спринт (тратит выносливость).  
- **Space:** прыжок.  
- **Ctrl / правый триггер:** подкат (roll), уменьшает хитбокс.  
- **E / X:** взаимодействие (открыть дверь, поднять предмет, поговорить).  
- **Tab / Start:** пауза / карта (минимальная, только для среза — показывать текущую зону).  
- **Мышь:** камера от первого/третьего лица (для среза — третье лицо с возможностью переключения, так как паркур лучше виден сверху/сбоку).

## 5. Прогрессия и сложность (вертикальный срез)

**Не RPG-прогрессия (нет уровней, статистики).** Прогрессия = знания игрока + открытые зоны + сюжетные триггеры.

- **Сложность нарастает линейно:** Глэйд (безопасно, обучение) → Первая секция Лабиринта (тёмная, один Гривер, простая головоломка) → Сдвиг (паника, бег) → Возвращение в Глэйд (эмоциональный релакс, диалог).  
- **Смерть:** не «конец игры» — игрок возвращается в последний чекпоинт (вход в зону или Глэйд) с минимальным штрафом (потеря предмета или временная усталость). Для среза — один чекпоинт в начале зоны.  
- **Проверка баланс:** для теста нужно пройти срез 3 раза — один раз без смерти, один раз с 1 смертью, один раз с максимальным стрессом (не искать подсказку). Цель: среднее время прохождения 10–12 минут.

---

## 6. Катсцены и сюжетные моменты (для среза)

- **Вступление:** Томас просыпается в Глэйде, Чак объясняет правила (кратко — диалог + UI текст).  
- **Момент сдвига:** анимация секции сдвига через `AnimationPlayer`, камера переключается на широкую, звук механизма + тревога.  
- **Первая встреча с Гривером:** стелс или уклонение — не бой, а побег.  
- **Возвращение:** Томас приносит подсказку (фрагмент карты) — диалог с Чаком, открытие следующей секции (триггер для расширения в будущем).  

> **Важно:** катсцены — это не отдельный движок, а сцены в Godot с `AnimationPlayer`, `Camera3D`, `AudioStreamPlayer`. Пропуск (skip) — через `InputEvent` в скрипте катсцены.

---

## 7. Определение успеха среза (Definition of Done — вертикальный срез)

- [ ] Игрок входит в Глэйд, видит Чака, читает/слышит правила.  
- [ ] Игрок проходит в Лабиринт, решает простую головоломку (3 блока).  
- [ ] Секция сдвигается, игрок может умереть или пройти.  
- [ ] Гривер появляется, игрок может избежать или уклониться.  
- [ ] Игрок возвращается в Глэйд с подсказкой.  
- [ ] Триггер открывает следующую секцию (для расширения).  
- [ ] Весь цикл проходит за 10–15 минут, без блокеров.  
- [ ] FPS стабилен (в идеале 60 на целевом железе, в sandbox — нет падений).  

---

## 8. Что вырезать при нехватке времени (резерв)

- Полная карта (оставить только мини-карту для текущей зоны).  
- Полная система диалогов с ветвлениями (оставить линейные диалоги с 2–3 выборами).  
- Боевая система с оружием (оставить только уклонение + камень).  
- Множественные типы Гриверов (оставить один — «стандартный» с патрулем и преследованием).  
- Секвентная музыка (оставить ambient + события, без оркестра).

## 9. Открытые вопросы (блокеры для следующего шага)

1. **Целевая версия Godot:** 4.2 LTS или 4.3? (Влияет на точный API SDFGI, Jolt-плагин).  
2. **Зона для среза:** первая секция после входа (ближе к Глэйду) или глубокий Лабиринт (сложнее визуально)?  
3. **Катсцена в срезе:** только вступление или также финальная сцена возвращения?  
4. **Геймпад:** полноценная поддержка или только клавиатура для среза?  
5. **Сохранения:** для среза — только чекпоинты или полноценное сохранение в файл?
