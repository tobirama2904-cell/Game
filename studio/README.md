# СТУДИЯ «ЧЕТЫРЕ ИСТОРИИ» — трейлеры и аудиокниги

Производственный конвейер цикла из четырёх книг:
**«Хроники Искры» (НОКС. Игры Тени)** · **«Костяной прилив»** · **«Странник»** · **«Разлом»**.

Всё производство — процедурное и воспроизводимое: кей-арт (AI), титры (PIL + кириллические
шрифты), саундтрек и SFX (чистый синтез numpy/scipy, без сэмплов), озвучка (мультикаст из
8 голосов), монтаж (ffmpeg: Ken Burns, xfade, грейдинг, плёночное зерно).

## Конвейер

```
studio/source/*.txt            исходники книг
studio/tools/adapt_strannik.py сценарий → разметка аудиокниги (script.json, clip_plan.json)
studio/tools/audio_synth.py    партитуры трейлеров, SFX, темы аудиокниги (синтез с нуля)
studio/tools/titles.py         титровые карточки (Oswald / Russo One / Yeseva One / Philosopher)
studio/tools/build_trailer.py  cue-sheet → MP4 (2 стадии: shot-рендер, затем xfade-сборка + звук)
studio/tools/build_audiobook.py клипы озвучки → главы MP3 с темами
studio/cues/*.json             раскадровки трейлеров (кадры, движение камеры, SFX, субтитры)
studio/site/                   веб-плеер (Range-сервер, манифест генерируется на лету)
```

Пересборка трейлера: `python tools/build_trailer.py cues/trailer_noks.json` (~7 мин).
Кэш 4K-апскейлов и WAV-миксы регенерируемы и исключены через `.gitignore`.

## Производственная смета озвучки

Лимит синтеза — 10 клипов за подход. Очередь:
1. трейлер «СТРАННИК» (5 клипов) + трейлер «РАЗЛОМ» (5 клипов);
2–5. аудиокнига «Странник»: 41 клип по главам (главы собираются автоматически по мере готовности);
6. сцены «в лицах» (радиопостановка ключевых сцен мультикастом) + общий тизер.
