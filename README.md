# После сигнала / After the Signal

Оригинальный короткий 3D-эпизод выживания в заброшенном лесном округе Орегона. Мара Рид пытается найти лекарство для брата Итана и отправить последнее сообщение по радио. Проект **не является** игрой The Last of Us и не использует её сюжет или ассеты.

## Играть

```sh
npm ci
npm run dev
```

Откройте адрес dev-сервера в браузере (поддерживается мобильный браузер с WebGL2). Сборка: `npm run build`; статический сайт появляется в `dist/`. Для телефона поверните экран горизонтально и пользуйтесь экранным джойстиком и свайпом справа.

**Управление:** WASD — ходьба; мышь — камера; ЛКМ — стрельба; Shift — бег; C — присесть; E — взаимодействие; R — перезарядить; H — лечиться; M — ориентиры. Мобильные кнопки встроены в интерфейс.

**Прохождение:** из начальной точки идите на север (по дороге к башне). Исследуйте станцию слева от дороги у координат (-31,-25) и прочтите записку; найдите лекарство в клинике справа (25,-64); дойдите до передатчика (0,-116). После финала можно продолжить исследование. Прогресс предметов и главы сохраняется в браузере.

## Статус и ограничения

Это **не APK** и не многосотчасовая AAA-игра: это запускаемый WebGL-эпизод с процедурно построенным окружением, врагами с обнаружением и преследованием, стрельбой, ресурсами, лечением, напарником, сценарием и финалом. Для Android APK ещё нужны отдельная нативная упаковка, Android SDK и тесты на устройстве. Пока реальный APK не создан, его нельзя называть готовым релизом. Для запуска нужен браузер с WebGL2 и доступом к локально обслуживаемым файлам. Обложка и три карты материалов (лесная почва, асфальт, бетон) созданы для этого проекта и находятся в `public/`. Остальные модели построены в коде, звук синтезируется; чужих игровых моделей и аудио в проекте нет. **Текущие персонажи и архитектура не фотореалистичны и не соответствуют качеству PS5 Pro** — скриншоты должны отражать реальную игру, а не рекламный концепт.

Read [Docs/UNREAL_SETUP.md](Docs/UNREAL_SETUP.md) for actual status, setup and limitations. This is not currently built or verified in Unreal: the engine and Android SDK are unavailable in this environment. The earlier WebGL game remains in `src/` for comparison; it is **not** an Unreal build.
